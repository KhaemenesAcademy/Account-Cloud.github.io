# Local Vault Boundary Contract v1

The Sovereign Mini Cloud OS reference build contains an encrypted browser-local Private/Black Hole Vault.

## Allowed role

A local encrypted vault may hold operator-owned backup artifacts, migration witnesses, or other deliberately local encrypted material when the operator understands that the data remains tied to that browser profile/device.

## Prohibited role

The local vault must not be treated as:

- canonical family identity storage;
- canonical learner identity storage;
- a cross-device account database;
- a session authority;
- a password/credential recovery oracle;
- a mastery/progression authority;
- proof that Mac and tablet are synchronized.

## Canonical path

Canonical family/learner records belong behind the protected STOS boundary and must bind to the existing sovereign storage layer after its runtime API is inspected and commissioned.

## Export rule

No real family/student data, password material, live tokens, or production secrets may be committed to the public Account Cloud GitHub repository or synthetic fixtures.
