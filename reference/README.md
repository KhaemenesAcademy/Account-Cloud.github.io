# Sovereign Mini Cloud OS Reference Witness

This directory preserves the newest Mini AGI / Sovereign Mini Cloud OS build that informed Account Cloud v0.1.1.

- Source title: `Sovereign Mini Cloud OS · Code Capsule`
- Source SHA-256: `f1575a7cf8dc0ddf213bee32e6e94050567a6c35d542625f9739d07e18c20bb8`
- Role here: architecture/reference witness only
- Canonical Academy account authority: **not this browser-local cloud**

The reference build contains a normal Mini Cloud `cloudFS` stored in browser `localStorage`, Code Capsule modularization controls, and a separate encrypted browser-local Private/Black Hole Vault stored in IndexedDB. Those mechanisms are useful for local tooling, recovery, and provenance, but they do not create cross-device canonical family or learner identity.

Account Cloud v0.1.1 therefore adopts the useful module/seam conventions while preserving the protected STOS storage boundary.
